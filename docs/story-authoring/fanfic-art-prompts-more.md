# Art for the 50 new fan fiction stories (Gemini app)

350 images across 50 stories, 7 per story. Made in the **free Gemini app** (gemini.google.com or the phone app), not the API, so it costs nothing.

Every story block resets the style and characters, restates them in full, and repeats a short style tag on every image line, so one story's look never leaks into the next. Every label (like `ZEL-03`) is unique across all 50 stories and tells me exactly which file it is.

**How to do it**

1. The stories are split into 10 parts of 5. Start a **new Gemini chat for each part**, so the chat never gets too long to remember the rules.
2. In the new chat, paste **Block 0** first. It sets the rules.
3. Paste the part's first story block. Gemini makes 4 images per reply. Type `next` for the next ones. If it skips or mixes one up, type `redo ZEL-05` (that image's label).
4. When Gemini says the story is finished, paste the next story block in the same chat.
5. If later images start to drift (wrong style, characters from an earlier story), paste that story's block again and type `continue from` and the label, for example `continue from ZEL-05`.
6. The free Gemini app has a daily image limit. When it says you've hit it, stop and carry on the next day: open a new chat, paste Block 0, paste the same story block and type `continue from` the next label.
7. Download the images and upload them to me as a zip, any order, any names. I'll recognise each picture, rename it, resize it and put it in the right story.

You don't have to do all of them. Any story without art still plays fine: the game simply skips pictures it doesn't have, and the story uses its theme colours instead.

## Block 0 (paste first in every new chat)

```
I need illustrations for several separate illustrated stories, in this one chat. I'll paste one story at a time.

Rules for the whole chat:
- Each story has its OWN art style and its OWN characters. When I paste a new story, treat it as a completely new project: forget the previous story's style, colours, characters and settings entirely.
- Make 4 images per reply, in the order listed. Above each image, write its label and file name on one line, for example: ZEL-01 cover.webp. Then wait until I type "next".
- No words, letters, captions, logos, signatures or watermarks inside any picture.
- Wide 16:9 landscape unless the item says Square 1:1.
- All characters are original characters; never copy official art of any game, show, film, book or actor.
- The reader is the hero of every story, and each picture is what the reader sees. NEVER draw the hero: no main character, and none of the reader's hands, arms, feet, back or reflection. Show the scene through the reader's own eyes, or with the hero simply absent. Other characters may look at, talk to or reach toward the viewer. If an item reads as if it needs the hero, leave them out and keep everything else.
- If I type "redo" and a label, make that image again following its story's style.
- If I type "continue from" and a label, carry on from that image in the current story.

Reply "Ready" and wait for the first story.
```
