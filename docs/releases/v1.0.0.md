# ZeroRoll v1.0.0

The first tagged release of ZeroRoll, an AI Game Master for solo tabletop roleplaying in the browser.

## Highlights

- **Bring your own model.** Play with Google Gemini, OpenAI, Anthropic Claude, xAI Grok, OpenRouter, GitHub Models, or any **local model** through the *Custom / Local LLM* provider.
- **Local models.** Point ZeroRoll at Ollama (`http://localhost:11434/v1`), LM Studio (`http://localhost:1234/v1`), vLLM, or any other OpenAI-compatible server. No API key is needed for local servers.
- Genre campaigns (fantasy, pirate adventure, samurai, gothic horror, cozy, romance, revenge, post-apocalypse and more) with premade heroes and seeded scenarios.
- Real dice rolls for action checks, a live character sheet, and genre-matched ambient music.
- Optional sign-in with cloud saves so a campaign can continue on another device.
- Keys stay in your browser. Nothing is proxied through a server.

## Using a local model

1. Start your local server with browser access allowed:
   - Ollama: `OLLAMA_ORIGINS="*" ollama serve`, then `ollama pull llama3.3`
   - LM Studio: start the Local Server and turn on CORS
2. In ZeroRoll, open the **Connect AI Provider & API Key** dialog and choose **Custom / Local LLM**.
3. Set the base URL (Ollama default is pre-filled), enter the model name you pulled, and leave the key blank.
4. Click **Test Connection**, then start a campaign.

Chrome, Edge and Firefox allow the hosted site to reach `http://localhost`. Safari blocks it, so on Safari run ZeroRoll locally instead (below).

## Running it yourself

- Download `zeroroll-v1.0.0-web.zip` below and serve the folder with any static file server (for example `npx serve`), or
- Clone the repo and run `npm install && npm run dev:vite`.
