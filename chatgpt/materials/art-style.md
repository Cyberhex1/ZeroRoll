# Picture style (all stories and the Lantern)

- Soft painterly anime illustration, cinematic lighting. No text, no logos, no watermarks, no signatures.
- Portraits: square, head and shoulders (final size 768 x 768).
- Cover and scenes: landscape, wider than tall (final width 1024 px).
- Make portraits first, then the cover, then the scenes. Repeat each character's `appearance` line word for word in every image prompt, so faces, hair and clothes match across images.
- File name = the art id from `story.json`. PNG is fine; Claude converts to WebP under 250 KB.
- The image used as `skin.backgroundArt` is shown dimmed behind the chat, so keep it calm and not too bright.
